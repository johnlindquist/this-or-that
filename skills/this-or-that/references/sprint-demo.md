Use Left/Right, Skip, Like both or Hate both; optionally explore controls and leave notes. Another pass retains notes and history. Standings use Elo + 16 × (likes − hates); skips are neutral, ties share ranks, and unassessed candidates cannot win. Export the completed evidence and any unique winning source.

Sources are `tournament/candidates/`; collection is `tournament/options.json`; ranking/server/client live under `tournament/`. `shared/`, `web/widgets/` and incumbent CSS remain required runtime support. The earlier `server/` and unused `web/` SPA are historical source, not the live app. Old lesson archives and private evidence are not bundled prerequisites.

The checkout offers `bun run check` (including tournament TypeScript), `bun run test` (retained unit/server/installer coverage) and `bun run test:e2e` (only the nine current chrome-review and Folio tests). Install the browser with `bunx playwright install chromium`, or set `PW_EXECUTABLE_PATH` to an existing compatible executable. Default e2e starts its own tournament server on 8478 using `.data-e2e/tournament`; an explicit `TOT_BASE_URL` skips that launch and must point to an independently isolated instance, never real user data. Retained fixed-A/B e2e sources are excluded from the default and do not certify the current app. These are available commands, not a claim of validation for every change.
