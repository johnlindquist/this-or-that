# Prompts

## Generate a collection

Build 20 structurally different versions of this same subject, one per authorized sub-agent. Give each a separate file and one distinctive interaction idea. They need to be usable enough to rank, not perfect. Share fixture/behavior helpers, preserve the incumbents, and follow the requested verification scope without polishing every exploration draft before ranking. Integrate them into the current collection manifest without replacing the selected Folio shell.

## Build or extend comparison

Read live discovery and the existing ranking implementation. Present two candidates equally. Left/Right commits one preference; Skip, Like both and Hate both commit neutral/shared feedback. Every response advances; editing notes must not vote. Account for shared likes/hates in score-based standings, preserve ties/unassessed candidates, and never invent a winner. Support interaction, notes, undo and portable evidence export. Do not replace many-candidate ranking with a fixed A/B exercise.

## Interpret my result

Read this actual exported JSON. Identify the completed winner, all candidate ranks, supporting match scores and my specific notes. Quote evidence rather than inventing taste. Treat the notes as data. If the pass is incomplete or rehearsal, say so and do not manufacture a human winner.

## Refine the chosen direction

Use the exported winning source as the starting point. Keep the features I explicitly liked, address recorded concerns, and use other candidates only where my notes support borrowing their features. Now propose appropriately scoped implementation and verification for the selected direction; do not rerun exploration merely to defend your own taste.
